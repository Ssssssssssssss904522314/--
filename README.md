# PrivMessenger Online

Полноценный веб-мессенджер: регистрация, вход, пользователи, история сообщений и real-time сообщения через WebSocket.

## Запуск

Нужен сервер с Node.js 20+.

1. Скопируйте `.env.example` в `.env`.
2. Задайте длинный случайный `JWT_SECRET`.
3. Выполните `npm install`.
4. Выполните `npm start`.
5. Откройте `http://localhost:3000`.

База SQLite создаётся автоматически в `privmessenger.db`.

## Важно для публикации

Для публичного сервиса нужен сервер/хостинг, HTTPS и домен. Не публикуйте `.env` и не отправляйте JWT_SECRET в чат.

Перед реальной эксплуатацией желательно добавить rate limiting, подтверждение номера, восстановление пароля, модерацию, лимиты сообщений, резервное копирование и PostgreSQL для большой нагрузки.
